Buscador de letras de música usando a API do Genius e interface em Streamlit.

---

## Visão Geral

O projeto `Lyric_Busca` foi desenvolvido para facilitar a busca e visualização de letras de músicas por meio de uma interface simples e prática. A aplicação combina Python, Streamlit e a API do Genius para permitir que o usuário pesquise músicas e obtenha letras de forma rápida e intuitiva.

O repositório tem foco em:

- busca por música e artista;
- consulta via API pública;
- apresentação da letra em interface amigável;
- experimentação com dados musicais e consumo de API;
- prototipagem de aplicação de busca textual.
